Tokenizer

Ordinary tokenizers cut Eritrean Tigrinya into pieces that are not words, so a model never learns how the language holds together and what it writes comes out broken. This tokenizer was trained on Eritrean Tigrinya, so a word stays a word. In training the language arrives as coherent pieces, and the model can learn to write it that way.
